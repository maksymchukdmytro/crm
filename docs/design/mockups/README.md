# Генератори макетів

Картинки-орієнтири для `docs/UI-DESIGN.md`. Це не код CRM.

- `common.py` — іконки lucide (`icons/`), шрифти, дані-приклади, функція `page()`.
- `v13_final.py` → картка замовлення (обрана схема); `v15_card.py` — та сама з компактними товарами.
- `v14_pages.py` → 10 сторінок (каркас, ТТН, товари, склад, покупці, налаштування).
- `v15_pages.py` → правки: головна, щільні списки, ліди, накладні, вікна товару й покупця, статистика.

Пізніші (30.10–03.11):
- `v17_mobile.py` — мобільна v2 (усі екрани); `v18_desktop.py` — ПК v2.
- `v20_orders_list.py` — список замовлень (5 варіантів; обрано таблицю, картки й скриньку).
- `v21`–`v24` — покрокове нове замовлення і вікно ТТН (ПК і телефон); `v25_order_card.py` — картка, варіанти A–E (обрано C).
- `v26_space.py` — «простір і поля»: телефон і доставка значками + 20 покращень (`docs/design/v26-prostir/`).
- `v27_mobile.py` — аудит телефону «Зараз → Стане», 18 покращень (`docs/design/v27-telefon/`); бере скриншоти
  з `/tmp/claude-0/walk/` (їх робить `scripts/ui-check/walk.py mob`).

Кадри з номерами покращень: функції `mk(n)` і `legend(...)` у `v26_space.py`.

Запуск: `python3 render.py v15_pages v15_card` → `out/<модуль>-<кадр>.png`.
Потрібні Playwright з Chromium (шлях — у `render.py`) і шрифти в `fonts/`
(Onest.ttf, Manrope.ttf, JetBrainsMono.ttf з Google Fonts; решта з `common.py` необов'язкові).
