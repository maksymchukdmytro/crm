Адреса для заявок

Надсилайте POST-запит на цю адресу з форми лендингу, конструктора сайтів або з вашого сервера.

{{ url }}

Поля

nameПІБ клієнта
phoneТелефон (обов'язково), у будь-якому форматі
sku або product_idТовар (артикул або ID із розділу «Товари»)
qty, priceКількість та ціна (якщо ціну не передано — береться з товару)
productsКілька товарів: JSON-масив [{"sku":"A1","qty":1,"price":499}]
comment, siteКоментар клієнта, назва лендингу
utm_source … utm_termМітки реклами
redirectКуди перенаправити клієнта після відправки звичайної HTML-форми (сторінка «Дякуємо»)

Приклад HTML-форми

<form method="post" action="{{ url }}">
  <input name="name" placeholder="Ваше ім'я" required>
  <input name="phone" placeholder="Телефон" required>
  <input type="hidden" name="sku" value="ART-001">
  <input type="hidden" name="site" value="landing-1">
  <input type="hidden" name="redirect" value="https://ваш-сайт/thanks.html">
  <button>Замовити</button>
</form>
<script>
// передаємо UTM-мітки з адреси сторінки у форму
var p = new URLSearchParams(location.search), f = document.forms[0];
["utm_source","utm_medium","utm_campaign","utm_content","utm_term"].forEach(function (k) {
  if (p.get(k)) { var i = document.createElement("input"); i.type = "hidden";
    i.name = k; i.value = p.get(k); f.appendChild(i); }
});
</script>

Через сервер (ключ не видно в коді сторінки)

<?php // order.php на вашому лендингу
$data = $_POST;
$data['utm_source'] = $_POST['utm_source'] ?? '';
$ch = curl_init('{{ url }}');
curl_setopt_array($ch, [CURLOPT_POST => 1, CURLOPT_RETURNTRANSFER => 1,
  CURLOPT_POSTFIELDS => http_build_query($data)]);
curl_exec($ch);
header('Location: thanks.html');

Як статуси впливають на склад

Резервувати — товар відкладається під замовлення (доступний залишок зменшується). Списати — товар фізично знімається зі складу (або з резерву). Повернути — списаний товар повертається на склад (ставте на статус, коли посилку фізично отримали назад). Зняти резерв — скасування до відправки. Кожна дія виконується один раз, повторна зміна статусу не дублює рух товару.
